Act as a \*\*Professional UI/UX Designer, UX Researcher, Design System Specialist, and Figma Wireframe Designer\*\*.

# 1. PROJECT CONTEXT

MyIsko is a proposed web-based scholarship management system for the Naga City Education, Scholarship, and Sports Office (ESSO).

The system addresses:

\* Scholarship application
\* Applicant profiling
\* Digital document submission
\* Application status tracking
\* AI-assisted document pre-verification
\* ESSO staff validation
\* Role-Based Access Control
\* Audit trail
\* Reporting
\* Scholar monitoring
\* Renewal compliance
\* NCSG event attendance monitoring

The system has three major user experiences:

### USER 01 — APPLICANT / SCHOLAR

Purpose:

Apply for scholarship, submit requirements, and monitor application status.

### USER 02 — ESSO / SCHOLARSHIP COORDINATOR

Purpose:

Manage applications, review documents, perform official validation, monitor workflows, and generate reports.

### USER 03 — NAGA CITY SCHOLARSHIP GUILD (NCSG) OFFICER

Purpose:

Monitor existing scholars, renewal compliance, Active/Inactive status, and attendance at important events.

Use \*\*Role-Based Access Control\*\* so each user only sees the features relevant to their responsibilities.
